# BlueMan NFT website

Static, responsive homepage prepared for deployment on Vercel.

## Deploy

Import this folder as a new Vercel project. No framework preset or build command is required; the site is served from the project root.

## Current scope

- Approved seven-section page structure and wording
- Responsive desktop and mobile layout
- Animated raincode hero background
- Smooth section navigation and restrained scroll reveals
- Reduced-motion accessibility support
